# Muhammad Al-amin Yusha'u Portfolio

An editorial portfolio for a communications strategist working across cultural
programming, public engagement and responsible technology.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm test
```

The site is built with Next.js, React and vinext for deployment through Sites.
Selected project evidence is stored in `public/assets`, and the downloadable CV
is stored in `public/downloads`.
